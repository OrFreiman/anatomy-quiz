# תרגול אנטומיה

Practice app for the anatomy course: quiz, question bank, movement table (טבלת התנועות) and a 3D muscle map (מפת השרירים בתלת-ממד).

Open it at https://orfreiman.github.io/anatomy-quiz/

## Credits

- 3D anatomy model: **BodyParts3D**, © The Database Center for Life Science, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The meshes were simplified and repacked (files in `m3d/`). Latissimus dorsi, rectus abdominis, internal oblique, transversus abdominis and quadratus lumborum are not in BodyParts3D and are approximate shapes drawn for this app.
- 3D rendering: [three.js](https://threejs.org/) r147 (MIT license), `m3d/three.min.js` and `m3d/orbit.js`.
